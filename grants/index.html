MAXIM — an open, verifiable trust layer for the AI-agent economy

Millions of AI agents are about to install MCP servers and transact with infrastructure they can't vet. MAXIM scores that infrastructure openly, verifies work on-chain, and (next) lets agents pay per query to check whether a server is safe to use — the x402-native trust oracle for MCP.

What grant funding builds

Milestone 1: expand the benchmark to 250+ servers + machine-readable feed. Milestone 2: ship the x402 metered trust-oracle endpoint — agents pay a micro-fee in USDC to query a server's readiness. Milestone 3: open-source the scoring core + embeddable badge + agent-registry integration.

Why fund this

It's a public good (open methodology, open score pages, open core), it advances the x402 agentic-payment standard, and it fills a real safety gap in the agent economy. Payment on-chain, milestone-based, no equity.

Honesty: confirmed commercial revenue to date is $0 — this is early-stage public infrastructure seeking milestone funding, and every claim on this page links to public evidence rather than a private metric. Readiness signals, not certification.
